# elieattali.github.io

Portfolio personnel publié sur GitHub Pages : <https://elieattali.github.io>

Site statique, sans étape de build :

- `index.html` : contenu (à propos, projets, compétences, contact)
- `assets/css/style.css` : styles, thèmes clair/sombre (tokens en tête de fichier)
- `assets/js/main.js` : bascule de thème, menu mobile, animations d'apparition

Aperçu local :

```sh
python3 -m http.server 8000
# puis http://localhost:8000
```
